Modelos de Clasificación de Imágenes

He desarrollado tres modelos de clasificación de imágenes utilizando técnicas de aprendizaje automático y redes neuronales convolucionales (CNN) y Transfer Learning (MobileNetV2). Estos modelos son capaces de identificar y clasificar objetos en imágenes con alta precisión.

  • Modelo 1: Clasificación de Comida medinte la técnica de aprendizaje no supervisado, clasifica 3 categorías Hamburgesas, Pizza y Perro Caliente

  • Modelo 2: Clasificación de Comida mediante la técnica de aprendizaje supervisado, clasifica 3 categorías Hamburgesas, Pizza y Perro Caliente

  • Modelo 3: Clasificación de Animales mediante la técnica de aprendizaje supervisado, clasifica 2 categorías Babuinos y Jirafas

    •

    Estos modelos han sido entrenado mediante tecnicas de aprendizaje supervisado y no supervisado, que consiste en entrenar un modelo con datos etiquetados (supervisado) o sin etiquetas (no supervisado) para que el modelo aprenda a identificar patrones y realizar predicciones.

    Los primeros 2 modelos han usado la técnica de Transfer Learning con MobileNetV2, lo que les ha permitido alcanzar una alta precisión con un tiempo de entrenamiento reducido. El tercer modelo se entrenó desde cero utilizando una arquitectura CNN personalizada lo que provoca un rendimiento más limitado y menos efectivo.

    Модели классификации изображений

    Я разработал три модели классификации изображений, используя техники машинного обучения и сверточные нейронные сети (CNN) и Transfer Learning (MobileNetV2). Эти модели способны идентифицировать и классифицировать объекты на изображениях с высокой точностью.

  • Модель 1: Классификация блюд с помощью метода неконтролируемого обучения: выделяется три категории: гамбургеры, пицца и хот-доги

  • Модель 2: Классификация еды с помощью метода контролируемого обучения: выделяется три категории: гамбургеры, пицца и хот-доги

  • Модель 3: Классификация животных с помощью метода контролируемого обучения: выделяется две категории: обезьяны и жирафы

    •

    Эти модели были обучены с помощью методов контролируемого и неконтролируемого обучения, которые заключаются в обучении модели на основе данных с метками (контролируемое обучение) или без меток (неконтролируемое обучение), чтобы модель научилась распознавать закономерности и делать прогнозы.

    В первых двух моделях использовалась техника переноса обучения с MobileNetV2, что позволило достичь высокой точности при сокращенном времени обучения. Третья модель была обучена с нуля с использованием настраиваемой архитектуры CNN, что привело к более ограниченной и менее эффективной производительности.

    Image Classification Models

    I have developed three image classification models using machine learning techniques, convolutional neural networks (CNNs), and transfer learning (MobileNetV2). These models are capable of identifying and classifying objects in images with high accuracy.

  • Model 1: Image classification of food using unsupervised learning technique, classifying 3 categories: Burgers, Pizza, and Hot Dogs

  • Model 2: Image classification of food using supervised learning technique, classifying 3 categories: Burgers, Pizza, and Hot Dogs

  • Model 3: Image classification of animals using supervised learning technique, classifying 2 categories: Baboons and Giraffes

    •

    These models have been trained using supervised and unsupervised learning techniques, which involve training a model using labeled data (supervised) or unlabeled data (unsupervised) so that the model learns to identify patterns and make predictions.

    The first two models used the transfer learning technique with MobileNetV2, which allowed them to achieve high accuracy with reduced training time. The third model was trained from scratch using a custom CNN architecture, resulting in more limited and less effective performance.
